Open engineer checks and decisions — check these before relying on the affected results

Checks (your own action)

  • Base Plate & Anchor: type 5.5 into f'c in Edge/Chrome; it should stay 5.5 (decimal fix tested headless only).
  • Concrete Beam ASD, Concrete Anchor: check the styling looks right after the Tailwind 3.4.17 pin.
  • Section Properties: AutoCAD MASSPROP sign check: 1 × 1 square at 0,0 should give XY = +0.25; note the principal-moment order.
  • Section Properties: AISC 360-16 Eq. E4-8, E4-9, F2-7 numbers; weld strength factors (J2.4, Table J2.5); HSS corner radii basis.
  • Timber: NDS 2018 equation numbers and the 3.3.3 / 3.3.3.7 wording; all "verify" reference values.
  • Timber: supply values not built in if wanted (SP Stud, SPF timbers, Dense/Non-Dense, other glulam).
  • Gusset: check all "verify" values against the printed MBE / FHWA guide / AASHTO.
  • Gusset: open an exported DXF in AutoCAD and MicroStation and re-import it.

Decisions

  • Gusset: stagger search band 2√(L·dn): remove it (recommended, more conservative)?
  • Gusset: which missing checks to add: chord splice / combined forces (O1), Whitmore clipping (O2), free-edge buckling (O3), eccentric groups (O4), heel shear plane normal force (O16).
  • Section Properties: plate against an HSS gives "J n/a" — handle it (recommended)?
  • Section Properties: shear flow with parallel load paths: switch bearing contacts off (recommended) or a stiffness split?
  • Section Properties: confirm Vx, Vy sign (force components along +x, +y).
  • Section Properties: keep the sections library on the Templates tab?
  • Section Properties: show machine-precision Validation differences as 0?

Full list with details: ENGINEER_CHECKS.md in the repository. Remove an item here and there when it is done.
