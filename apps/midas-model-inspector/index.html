MIDAS Civil NX Model Inspector

Read the JSON behind any part of the open model · copy it as an API request · record what a GUI change does

Civil NX connection

Not checked. Civil NX must be open with a model, and "Connected" in Apps → API Settings.
Shares the Base URL / key / proxy setting with the continuous beam app. Everything here only reads the model (GET), except the two Export buttons, which write a file on the Civil NX PC.

Endpoints

Empty items (nothing defined in the model) are skipped. Tip: set up a feature once by hand in Civil NX, then read its endpoint; "Copy as Assign" gives the request body an app sends to create the same thing.

Record a change (snapshot → compare)

Like recording a macro: take a snapshot, make the change in Civil NX by hand, then compare. The result lists every endpoint that changed and the records added, changed or removed, as ready-to-send JSON.
No snapshot. The snapshot reads every endpoint in the list (about a minute).

Export whole model (file on the Civil NX PC)

Civil NX writes the file itself (to <folder>\model_<date-time>.json / .mct); the folder must exist on that PC.
