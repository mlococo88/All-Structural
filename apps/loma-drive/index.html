About this model

Tap any element for details. Geometry traced from the permit set vectors (1/4"=1'-0"). Elevations in the plan's datum (1st floor 29.20'). Site: house placed on the MassGIS roof outline of the existing house (plan north ≈ 28° east of true north); terrain fit to USGS 3DEP lidar spot elevations, whose NAVD88 values match the plan's datum; streets from Census TIGER/Line; neighbours are generic massing on MassGIS outlines. Approximate — not a survey.

Data sources: Taormina Architects permit set (May 13 2026); MassGIS Building Structures and 2023 orthoimagery; USGS 3DEP lidar (EPQS); US Census TIGER/Line streets; Esri World Geocoder for the address point.
