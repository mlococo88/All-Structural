Prestressed Bridge Design has moved

Prestressed Bridge Design is now the folder app apps/ps-bridge/index.html in this repository folder, with the same prestressed engine at the bridge level.

This browser keeps a design saved by the old Prestressed Bridge Design. In Firefox and Safari each file has its own storage, so the new app cannot see it. Download it here, then open the new app and use Project tab → From the old app → Import an old-app JSON file….

In Chrome or Edge the design is already there: the new app offers it when it opens. This page shows this offer once. Nothing saved is deleted.
