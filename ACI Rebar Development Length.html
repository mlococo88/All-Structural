Rebar Development & Splices is now part of Concrete Beam Capacity

The standalone calculator was retired. Use the Development & Splice tab of Concrete Beam Capacity.html (the Concrete Beam Design Suite), in the same folder. It is the same calculator.

This browser keeps rebar data saved by the old file. In Firefox and Safari each file opened from the computer has its own storage, so Concrete Beam Capacity cannot see it. Download it here, then open the Development & Splice tab, use Import JSON (input tab "Assumptions & Save") and, for a saved project, Save it under its name.

In Chrome or Edge the projects are already listed in the tab; you do not need the files. This page shows this offer once and deletes nothing.
