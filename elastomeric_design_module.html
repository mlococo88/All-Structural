Pad to the Abutment app
Sends the designed pad back to the Abutment app that opened this one (a JSON file when opened on its own). It sends the G of the shear force (Method B Gmax; Method A and plain pads the highest G of the durometer range) with Hbu, and is not sent while an input error stands. When the Abutment app opens this module again with that same G, the specified G (panel I-3) is not changed.
